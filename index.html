01 — HTML

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure and content of a webpage.

</>

Structure

HTML creates the structure of a webpage using elements and tags.

H1

Headings

Use heading tags such as h1, h2, and h3 to organize content.

IMG

Images

The img element allows you to add images to your webpage.

HTML Example

<h1>My Website</h1>

<p>Welcome to my website!</p>

<a href="https://example.com">
Visit Website
</a>

02 — CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to design and style HTML webpages.

🎨

Colors

CSS lets you change text, background, and border colors.

📦

Layout

Use Flexbox and Grid to create modern webpage layouts.

✨

Design

Add shadows, borders, animations, spacing, and more.

CSS Example

body {
background-color: #f4f7fb;
}

h1 {
color: #2563eb;
font-size: 40px;
}

p {
color: #555;
}
